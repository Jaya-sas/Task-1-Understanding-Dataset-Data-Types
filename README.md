# Task 1: Understanding Dataset & Data Types
## Internship Task – AI & ML
### Objective
The objective of this task is to understand the structure of a dataset, identify different data types, analyze data quality, and determine the dataset’s suitability for machine learning.
### Dataset Used
- Titanic Dataset
### Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab
### Steps Performed
1. Loaded the dataset using Pandas
2. Displayed first and last few records
3. Identified numerical, categorical, ordinal, and binary features
4. Used `df.info()` and `df.describe()` for data understanding
5. Checked unique values in categorical columns
6. Identified target variable and input features
7. Analyzed dataset size and ML suitability
8. Observed data quality issues such as missing values and imbalance
### Target Variable
- `Survived`
### Conclusion
This task helped me understand how data exploration and understanding are critical before building machine learning models.
